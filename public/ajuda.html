🚀 Primeiros passos

Como criar minha conta no Axcend

Acesse /signup e preencha:

  • Nome da empresa — vai aparecer no painel
  • Subdomínio — escolha um nome (ex: acme). Seu painel ficará em acme.centralaxcend.com
  • Seu nome e email — você vira admin (Diretoria)
  • Senha — mínimo 6 caracteres

Após criar, você ganha 14 dias grátis sem cartão de crédito.

O que tá incluído no Trial?

Trial de 14 dias inclui:

  • Até 5 usuários
  • Até 100 demandas
  • RH, Financeiro, Spy, AdLib completos
  • Sem IA WhatsApp (precisa Pro)
  • Sem Spy Wolf Master (precisa Basic+)

Veja todos os limites em Configurações → 💎 Meu Plano.

Como adicionar minha equipe

Vai em ⚙️ Configurações → 👥 Usuários:

  1. Clique em "+ Novo usuário"
  2. Preencha nome, email, senha
  3. Escolha o cargo (Diretoria, Copy, Editor, Gestor de Tráfego, Spy, Infra)
  4. Coloque o WhatsApp pra receber notificações
  5. Salvar

O novo usuário pode logar imediatamente com o email/senha que você definiu.

Como personalizar cores e logo (Branding)

Disponível no plano Pro+. Vai em ⚙️ Configurações → 🎨 Branding:

  • Cor primária (botões, destaques)
  • Cor secundária (gradientes)
  • Cor de fundo
  • Logo (URL pública da imagem)
  • Favicon

As mudanças aparecem pra todos os usuários do seu tenant imediatamente.

Como navegar pelo painel

Menu lateral esquerdo tem todos os módulos:

  • 🏠 Início — dashboard com KPIs
  • 📋 Demandas — tarefas do time
  • 📅 Rituais — planejamento semanal
  • 👥 Gestão — RH, Financeiro, Vagas (sub-abas)
  • 🎨 Criativos / 🕵️ AdLib — gestão de criativos
  • ⚙️ Configurações — todas as configs do sistema

📋 Demandas e Rituais

Como criar uma demanda

Clique em 📋 Demandas → "+ Nova Demanda". Preencha:

  • Nome — descreva o que precisa ser feito
  • Responsável(is) — quem vai fazer
  • Prazo — quando precisa estar pronto
  • Prioridade — alta/média/baixa
  • Descrição — detalhes adicionais

Dica: você pode criar pelo WhatsApp dizendo "cria demanda pra Ana revisar VSL até sexta" 🤖

Como funcionam os status

4 status principais: BACKLOG → EM_ANDAMENTO → REVISÃO → CONCLUIDO. Arraste no kanban ou edite no modal.

Como funciona o Ritual Semanal

📅 Rituais tem ferramentas pra planejamento semanal: review de criativos, alocação do time, métricas, Spy manual. Toda sexta às 18h o sistema gera um relatório automático e envia pra Diretoria.

Como delegar via WhatsApp

Configure WhatsApp em Configurações → 💬 WhatsApp. Aí você pode mandar:

  • cria demanda pra Ana revisar VSL até sexta
  • delega #847 pra Carlos também
  • concluir #123
  • /relatorio copy semana
  • /minhas (suas demandas)
  • /risco (demandas atrasadas)

👥 RH

Cadastrar colaborador

Gestão → RH → Colaboradores → "+ Novo". Preencha dados pessoais, cargo, regime (CLT/PJ), salário, banco e admissão.

Como funciona a Folha PJ

RH → Folha PJ. Lista automática de todos os PJs ativos. Edite os dias trabalhados → cálculo proporcional. Cole link da NF. Aprove → "Exportar pro Financeiro" cria lançamento de despesa.

Como rodar eNPS

RH → eNPS → "+ Novo ciclo". Defina nome, datas, pergunta principal e mensagem WhatsApp. Anônimo. Histórico mostra evolução.

Como fazer offboarding

RH → Offboarding → "+ Iniciar". Modal completo: motivo detalhado, feedback do colab, pontos positivos, sugestões, avaliações, próximos passos. Checklist com 31 itens em 7 categorias.

💰 Financeiro

Como criar um lançamento

Gestão → Financeiro → Lançamentos → "+ Novo". Receita ou despesa, valor, data, categoria, conta, status (pago/pendente/atrasado).

O que é o DRE

Demonstrativo de Resultado: receitas vs despesas por categoria, mês a mês. Use pra ver lucro real, margem %, top categorias de despesa.

Como conciliar OFX do banco

Baixe extrato do banco em OFX (Nubank, Itaú, Inter, etc). Financeiro → OFX → Importar. Sistema bate data+valor com seus lançamentos pra conciliar automaticamente.

Calcular impostos Simples Nacional

Financeiro → Impostos. Cálculo automático do DAS Anexo III baseado na receita dos últimos 12 meses. Mostra alíquota efetiva e quanto pagar mês a mês.

Como cadastrar NF

Financeiro → NFs → "+ Nova NF". Número, tomador, descrição, valor. Ao marcar como Emitida, sistema oferece criar lançamento de receita automaticamente.

🏢 Vagas e Recrutamento

Como publicar uma vaga

Gestão → Vagas → "+ Nova Vaga". Título, descrição, requisitos, perguntas customizadas, teste prático opcional. Marca como "publicada" → ela aparece em /vagas e candidatos podem se candidatar.

Como funciona o IA Score

No detalhe de cada candidato, clique em "✨ Analisar com IA". O Claude analisa as respostas + portfolio + teste prático e dá nota de 0-100 com prós/contras. Requer chave Anthropic configurada.

Teste prático embutido

No editor de vaga, ative "Teste prático". Briefing, critérios de avaliação, link de entrega. Candidatos acessam /teste/[slug] e enviam entrega. Você vê tudo no detalhe.

Como usar o kanban de candidatos

Drag & drop entre colunas: Triagem → Entrevista → Teste → Aprovado/Reprovado. Cada movimento dispara evento Utmify (se configurado).

🔌 Integrações

Como conectar o WhatsApp (Z-API)

Configurações → WhatsApp + Agente IA. Cole Instance ID e Token da Z-API. Configure o webhook /api/whatsapp/webhook no painel Z-API. Cadastre WhatsApp dos usuários em Configurações → Usuários.

Como conectar o agente IA (Claude/OpenAI)

Pegue API Key em console.anthropic.com. Configurações → WhatsApp → Agente IA. Cole o token. Cliente pode delegar e perguntar via zap em linguagem natural.

Como conectar Utmify

Pegue API Token em utmify.com.br. Configurações → 🔌 Integrações → Utmify. Cole token + escolha quais eventos enviar (lead, qualified, opportunity, conversion).

Como conectar RedTrack

Configurações → APIs externas → RedTrack. Cole API Key. Sistema importa métricas de Meta/Google/TikTok Ads pra calcular ROAS por oferta/criativo.

Como usar Spy Wolf

AdLib → Spy Automático. Cadastre bibliotecas concorrentes. Use o gerador de plano pra encontrar novas. Importe entregas da skill Spy Wolf via webhook ou cola manual.

⚙️ Conta e Pagamento

Como mudar minha senha

Clique no seu nome no canto superior → "Minha conta" → "Trocar senha". Precisa da senha atual + nova senha (mín 6 chars).

Esqueci minha senha

Na tela de login, clique em "Esqueceu a senha?". Digite seu email → vai chegar um link de reset (válido 1h).

Como fazer upgrade do plano

Configurações → 💎 Meu Plano. Veja seu uso atual vs limite. Clique no plano superior → vai pro checkout do Pagar.me. Após pagamento, plano ativa automaticamente.

Como cancelar minha assinatura

Por enquanto, mande email pra suporte@centralaxcend.com. Em breve teremos botão direto no painel. Cancelamento mantém acesso até fim do ciclo já pago.

Como exportar meus dados (LGPD)

Direito da LGPD. Mande pedido pra privacidade@centralaxcend.com. Em até 15 dias enviamos JSON com todos seus dados.

🕵️ Spy e AdLib

Diferença entre AdLib e Spy Wolf

AdLib: cadastro manual dos anúncios de concorrentes que você quer arquivar. Spy Wolf: monitoramento automático de tracking domains de operações DR em vários nichos, com banco master atualizado diariamente.

Como adicionar anúncio no AdLib

AdLib → "+ Adicionar Anúncio". Anunciante, plataforma (FB/IG/TT/YT/Google), tipo, nicho, link, estrelas (rating), observações. Tudo vai pro Swipe File.

Como funciona o Banco Master Spy

O Axcend roda Spy Wolf diariamente em 10+ nichos populares e popula o "Banco Master". Todos os clientes do plano Basic+ veem esses dados automaticamente. Você não precisa rodar nada.
