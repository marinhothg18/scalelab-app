🌍 DNS wildcard *.axcend.com
Pra qualquer subdomínio (acme, vortex, etc) funcionar de verdade, precisa configurar no Cloudflare/Railway. Trabalho externo de ~2h.
Passo a passo
  1. Comprar dominio: registrar axcend.com (ou nome do produto SaaS) no Registro.br ou Cloudflare
  2. Nameservers: apontar pra Cloudflare
  3. Criar CNAME wildcard: * → seu-app.up.railway.app
  4. Railway: em Settings → Domains, adicionar *.axcend.com
  5. SSL: Cloudflare emite automático (Full strict)
  6. Teste: curl https://acme.axcend.com/api/ping
